# Mailwell Releases

Downloads and the Sparkle update feed for [Mailwell](https://lukesc.gumroad.com/l/mailwell) —
the fast, private, native email client for Mac.

- **Latest release:** see [Releases](../../releases/latest)
- Auto-update feed: `appcast.xml` attached to each release

The app checks this feed for updates; every build is Developer ID-signed
and notarized. Source code lives in a private repository.
